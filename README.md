#  Облік книг

Консольна програма на C++ для ведення каталогу книг.
Дозволяє додавати, шукати, сортувати та виводити книги.

##  Збірка та запуск

### Вимоги
- Компілятор g++ (підтримка C++11 або вище)
- ОС: Windows 

## Структура проєкту

```
src/
├── main.cpp       # Головна логіка та меню
├── book.cpp       # Алгоритми пошуку та сортування
├── io.cpp         # Введення/виведення даних
docs/
├── tasks.md       # Розподіл завдань
README.md
```

##  Функціонал

-  Додати книгу (назва, автор, рік, жанр, статус)
-  Пошук за назвою або автором
-  Виведення всього каталогу
-  Сортування за роком або алфавітом
-  Видалення книги

##  Учасники

 **Юра**  Структура даних, заголовні файли, main.cpp, меню 
 **Віка**  Алгоритми пошуку та сортування 
 **Паша**  Введення/виведення, відображення результатів, документація
